# BI POLARIZE ENTERPRISES, INC. Website

Clean production website for BI POLARIZE ENTERPRISES, INC. and the P.O.L.A.R. operating experience.

## Principles

- Mobile-first before cinematic enhancement
- Approved brand assets only
- Fast, accessible, and readable by default
- No oversized production images
- No blocking intro sequence
- One stable release after preview verification

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run typecheck
npm run build
```

## Deployment

The repository is intended for Vercel deployment. Preview deployments must be tested before the `polarpaw.online` production domain is reassigned.
